# Mental Health Assistant

## Project Overview

Mental Health Assistant is a simple AI-based supportive wellness information application.

The application allows users to enter how they are feeling and provides general supportive suggestions.

## Features

- Simple and user-friendly interface
- Users can describe how they are feeling
- Provides general supportive suggestions
- Built using Python and Streamlit

## Technologies Used

- Python
- Streamlit
