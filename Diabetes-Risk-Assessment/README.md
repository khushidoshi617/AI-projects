# Diabetes Risk Assessment

## Project Overview

Diabetes Risk Assessment is a simple educational web application that demonstrates how basic health-related inputs can be used to calculate a simple risk score.

## Features

- Age input
- BMI input
- Glucose level input
- Family history input
- Physical activity input
- Simple risk-score calculation
- Easy-to-understand result

## Technologies Used

- Python
- Streamlit
