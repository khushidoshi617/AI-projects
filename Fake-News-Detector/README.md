# Fake News Detector

## Project Overview

Fake News Detector is a simple web application that analyzes news text for potentially suspicious language.

## Features

- Enter news text or an article
- Analyze the entered text
- Detect potentially suspicious keywords
- Display an easy-to-understand result

## Technologies Used

- Python
- Streamlit
- Natural Language Processing concepts
