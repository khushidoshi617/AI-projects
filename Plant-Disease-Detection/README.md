# Plant Disease Detection

## Project Overview

Plant Disease Detection is a web application that demonstrates how plant leaf images can be analyzed for disease identification.

## Features

- Upload plant leaf images
- Display uploaded images
- Provide a demonstration detection result
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- Pillow
- Machine Learning
